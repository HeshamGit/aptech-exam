## 🎓 Diplomas Covered

This repository organizes past papers and sample exams across the three flagship Aptech diploma curricula:

1. **CPISM** — *Certificate of Proficiency in Information System Management*
2. **DISM** — *Diploma in Information System Management*
3. **ADSE** — *Advanced Diploma in Software Engineering (ACCP)*

* **Fundamentals of Internet of Things (IoT)**

## 🚀 How to Use These Resources

1. **Self-Study & Revision:** Browse any subject directory to inspect past sample exams with highlighted verified answer keys.
2. **Interactive Timed Testing:** Open the [AptechExam Web Portal](https://heshamgit.github.io/AptechExam/) in your browser to experience a real 45-minute timed simulation.
3. **Mobile Offline Practice:** Download the latest [AptechExam APK](https://github.com/HeshamGit/AptechExam/releases/latest) for 100% offline access with streak counters and dark mode.
4. **Deep Dive Reading:** Cross-reference difficult concepts with official course textbooks in [aptech-book](https://github.com/HeshamGit/aptech-book).
